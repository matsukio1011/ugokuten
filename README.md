# 動く点 — 図形と関数の実験室

中学生向けの数学学習アプリです。図形や点を動かし、時間と面積の関係をグラフで確認できます。

## 使い方

リポジトリをダウンロードして、`index.html` をブラウザで開いてください。インストールやビルドは不要です。`dist/index.html` からも開けます。

PCでは左に図、右にグラフ、その下に解説が表示されます。再生ボタン、時間スライダー、説明の切り替えボタンで操作します。

## 収録問題

1. 三角形の重なり
2. 台形のシールはがし
3. 長方形を動く２点
4. 正方形を動く２点
5. 途中で止まる点Q
6. 正方形を３辺進む点P
7. 正方形と三角形の重なり
8. 三角形が長方形を通り抜ける
9. 長方形を動く点Pと面積
10. 直角三角形を動く点Pと面積

## ファイル構成

- `index.html`：アプリを開く入口
- `dist/index.html`：問題選択画面
- `dist/*.html`：各問題の画面
- `dist/*.js`：アニメーション、計算、解説
- `dist/shared.css`：共通の見た目
- `dist/lesson-layout.css`：図・グラフ・解説の配置

変更する場合は `dist` 内のファイルを編集します。`dist` は自動生成物ではなく、アプリ本体です。

ネット接続なしで動作し、外部サービスやAPIキーは使用しません。

## 長方形を動く点Pと面積

問題一覧の「長方形を動く点Pと面積」から開けます。`dist/moving-point-area.html` を直接開くこともできます。

- 元の問題（横4 cm・縦3 cm）と、数字を変えた5セットを切り替えられます。
- 点P・スライダー・グラフをドラッグすると、三角形APDと面積のグラフが連動します。
- Aから点Pまで進んだ道のりxを、辺に沿ったオレンジ色の線で表示します。
- 再生・一時停止、式と変域の表示、全体のグラフの表示に対応します。
- PCではダークモードの画面内で操作でき、スクロールは不要です。「全画面表示」で画面を広く使えます。

選んだ問題と位置、表示設定は、ブラウザのローカルストレージが利用できる場合に保存されます。

## 直角三角形を動く点Pと面積

問題一覧の「直角三角形を動く点Pと面積」、または `dist/right-triangle-area.html` から開けます。

- 点PがA→B→Cと進むと、三角形APCの面積とグラフが連動します。
- 元の問題（AB＝4 cm・BC＝3 cm）と数字を変えた5セットを切り替えられます。
- 道のりxは辺に沿ったオレンジ色の線で表示します。
- 点P・スライダー・グラフのドラッグ、再生・一時停止、式と変域の表示に対応します。分数は上下に重ねて表示します。
- ダークモード、PC画面でスクロール不要の配置、全画面表示に対応します。

インストール・ビルド・ネット接続は不要です。ローカルストレージが利用できる場合は、問題と位置、表示設定を保存します。
